Pengertian Sistem Komputer

Konsep dasar bagaimana komputer bekerja sebagai sebuah sistem.

"Kumpulan perangkat komputer yang saling berhubungan dan berinteraksi untuk melakukan proses pengolahan data menjadi informasi."

3 Komponen Utama

🔧

Hardware

Perangkat Keras — bagian fisik yang dapat dilihat dan disentuh langsung.

💿

Software

Perangkat Lunak — program atau instruksi yang menjalankan perangkat keras.

👤

Brainware

Pengguna — manusia yang mengoperasikan dan mengendalikan komputer.

🚲

Analogi: Sistem Komputer itu Seperti Sepeda

  • Hardware = rangka, roda, pedal (bagian fisik).

  • Software = teknik mengayuh dan aturan berkendara.

  • Brainware = kamu yang mengendarai sepeda.

💡 Tanpa salah satu komponen, sepeda tidak bisa digunakan. Begitu juga komputer.

Pengertian Hardware

Definisi dan karakteristik fisik komputer.

Perangkat keras (hardware) adalah komponen elektronik pada komputer yang berwujud fisik, dapat dilihat kasat mata, dan dapat disentuh.

📋 Ciri-ciri Utama

  • Berwujud fisik

    Dapat dilihat dan disentuh.

  • Bentuk nyata

    Berupa komponen elektronik/mekanik.

  • Butuh daya listrik

    Mayoritas bergantung pada listrik.

  • Menjalankan instruksi software

    Bekerja berdasarkan perintah perangkat lunak.

Contoh Aplikasi Nyata: Mengetik Dokumen

CPU mengolah ketikanmu (Proses).

Hasil tulisan muncul di Monitor (Output).

Kamu menyimpan file di Hardisk/SSD (Simpan).
